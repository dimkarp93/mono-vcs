# CLAUDE.md

## Code comments

Never write comments — not in code, not in tests. No `//` line comments, no
`/* */` block comments, no doc comments, no comments inside test cases.

This applies to all code you add or modify in this repository. Write the code so
it is self-explanatory through clear naming and structure instead of explaining
it with comments. If you touch a file that still has comments, remove them.
